1 · Steps

Steps per role

How values move. Each value moves to the nearest step in its role. Distance is measured in log-odds, so going from 5% to 10% counts the same as going from 90% to 95%. Values more than log-odds from every step stay as lint errors. Text only moves toward more opaque, so contrast never drops. If two different opacities of one color on one line (a resting state and its hover, for example) would land on the same step, both are left alone.
